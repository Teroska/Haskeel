# Навчальний проєкт CI/CD

Цей проєкт демонструє базовий цикл CI/CD з використанням Bash-скриптів та GitHub Actions.

## Локальний запуск
Для запуску всіх етапів виконайте:
1. `bash scripts/setup.sh` — встановлення бібліотек.
2. `bash scripts/test.sh` — запуск тестів (результат у `reports/test_output.txt`).
3. `bash scripts/build.sh` — створення метаданих (результат у `artifacts/build_info.txt`).

## Конфігурація CI
Workflow налаштований у файлі `.github/workflows/ci.yml`. Він запускається автоматично при кожному push або PR.

## Експеримент з помилкою
Щоб перевірити збереження артефактів при падінні:
1. Змініть `assert add(2, 3) == 5` на `== 6` у `tests/test_main.py`.
2. Зробіть push.
3. Перевірте вкладку **Actions** — крок "Run Tests" буде червоним, але артефакт "project-results" буде доступний для завантаження.
